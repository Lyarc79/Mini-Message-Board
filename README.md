# Mini MessageBoard
Message board application built with Node.js, Express, and EJS following the MVC architechtural pattern. It focuses on backend functionality, featuring data persistence using a Neon PostgreSQL cloud database with safe connection pooling via `pg`. It also includes robuts server-side validation and error handling using `express validator`.
